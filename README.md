### 🤖 2. Nauli Dental Care — AI Assistant

An AI-powered clinic information system integrating a chatbot and workflow automation to improve access to clinic information and services.

**Technologies:**
`Next.js` `FastAPI` `Python` `PostgreSQL` `RAG` `LangChain` `Cohere AI` `n8n` `Docker`

### ⚙️ 3. SISTAN — Automatic Object Counting & Sorting System

An IoT-based miniature conveyor system designed to count and automatically sort objects using sensors and motor control.

**Technologies:**
`Arduino Uno` `Infrared Sensor` `Servo Motor` `DC Gearbox` `L298N`

An AI-powered travel assistant for Lake Toba that helps users create personalized travel plans, estimate budgets, and explore accommodation and transportation options.

The project also explores analyzing visitor reviews to provide insights for local businesses and destination managers.

**Technologies:**
`Python` `RAG` `LoRA Fine-Tuning` `LangChain` `FastAPI` `Next.js` `PostgreSQL`
